## Adding a New WebIDL Interface

To add a new WebIDL interface and its implementation to WebKit, follow these steps:

1. Create all necessary files — e.g, `Foo.idl`, `Foo.h`, and `Foo.cpp` — in the appropriate directories.
2. Find an existing `.idl` file that’s for a WebIDL interface similar to the one you’re adding.<br>
For the purposes of these steps, let’s call that file `Bar.idl` here.
3. Run a (rip)grep (or similar) search for `\W(JS)?Bar\.(idl|cpp|h)|macro\(Bar\)`, to find config files with lines containing any of `Bar.idl`, `Bar.h`, `Bar.cpp`, `JSBar.h`, `JSBar.cpp`, or `macro(Bar)`.
4. For each matching `Bar.idl`, `Bar.h`, or `Bar.cpp` line you find, add a corresponding `Foo.idl`, `Foo.h`, or `Foo.cpp` line (for the files you created in step <span>#</span>1)
5. For each matching `JSBar.h` or `JSBar.cpp` line you find, add a corresponding `JSFoo.h` or `JSFoo.cpp` line (for JS bindings files generated by the build).
6. For any `macro(Bar)` line you find, add a corresponding `macro(Foo)`line.
6. Run the build.
7. If the build fails, repeat steps 2 to 7 as needed.

For step <span>#4</span>, the files in the [`Source/WebCore`](https://github.com/WebKit/WebKit/tree/main/Source/WebCore) subdirectory that you’ll likely need to add lines to are the following:

- [`CMakeLists.txt`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/CMakeLists.txt) needs a line for `Foo.idl`
- [`DerivedSources-input.xcfilelist`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/DerivedSources-input.xcfilelist) needs a line for `Foo.idl`
- [`DerivedSources-output.xcfilelist`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/DerivedSources-output.xcfilelist) needs lines for `JSFoo.h` and `JSFoo.cpp`
- [`DerivedSources.make`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/DerivedSources.make) needs a line for `Foo.idl`
- [`Headers.cmake`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/Headers.cmake) needs a line for `Foo.h`
- [`Sources.txt`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/Sources.txt) needs lines for `Foo.cpp` and `JSFoo.cpp`
- [`WebCore.xcodeproj/project.pbxproj`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/WebCore.xcodeproj/project.pbxproj) needs lines for `Foo.idl`, `Foo.h`, and `Foo.cpp`

You _may_ also need to make the following changes:

- [`bindings/js/WebCoreBuiltinNames.h`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/bindings/js/WebCoreBuiltinNames.h) _may_ need a `macro(Foo) \` line<br>
  (This is necessary when you’re using the `EnabledBySetting` annotation in any WebIDL files you’re adding)
- [`WebCore.xcodeproj/project.pbxproj`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/WebCore.xcodeproj/project.pbxproj) _may_ need lines for `JSFoo.h`, and `JSFoo.cpp`<br>

Also for step <span>#4</span>: See https://docs.webkit.org/Deep%20Dive/Build/AddingNewFile.html for details on using Xcode to add new files to the project — which will modify the [`WebCore.xcodeproj/project.pbxproj`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/WebCore.xcodeproj/project.pbxproj) file. But, for any `JSFoo.h` and `JSFoo.cpp` files, you might also need to make _manual_ modifications to the [`WebCore.xcodeproj/project.pbxproj`](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/WebCore.xcodeproj/project.pbxproj) file — to assign each file a unique hash (fileref/UUID), and to adjust the paths for those files.
